# Security and privacy

Do not post tokens, Rclone configurations, Google client JSON, passcodes, private save files or complete authentication logs in public issues.

Use GitHub's private vulnerability reporting on this repository when available. For ordinary bugs, provide a minimal synthetic reproduction and redact account/device identifiers.

The extension's passcode is local application privacy, not encryption of game saves or a defense against code running as the same Windows user. Cloud encryption at rest is provided by your storage provider or an Rclone crypt remote you configure.

Device removal is cooperative: revoke provider authorization separately when a device is lost. Copies already synchronized to a device are not remotely erased.
