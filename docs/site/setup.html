Get started

Connect your devices.

1. Install

  1. Download the latest release and choose the .pext asset.
  2. Open it with Playnite, approve installation and restart Playnite.
  3. Open Playnite menu → Playnite Link → Personal cloud account & settings.

2. Connect storage

Reuse an authorized Rclone remote, or create a Google Drive, Dropbox or OneDrive connection. Authorize your account on each device. Choose the same account and vault folder (normally PlayniteLink) everywhere.

Google Drive: an extra setup step

A new Google connection currently needs your own Desktop OAuth client JSON. Follow Rclone’s official setup instructions: create a Google Cloud project, enable Drive API, configure consent, create a Desktop app client and download its JSON. Select that file in Playnite Link and authorize your account. Testing-mode apps can need reauthorization; see the official guide for production and verification requirements.

Keep client JSON and Rclone configuration private. Current Drive permissions can manage Drive files, though extension operations target your configured vault. No developer’s personal OAuth credentials are bundled.

3. Choose games

Fresh profiles automatically link unambiguous library-provider identities. Review manually added games or duplicate identities. To add a game, right-click it → Playnite Link → Enable and migrate playtime. Select its dedicated save folder on each device. Save paths are not guessed.

4. Add another device

Install the extension there and connect the same vault. Each device is an equal participant. Check the device roster and review conflicts. Sharing extension and theme installations is optional; changing an active theme does not select it on another device.

Optional integrations

GameActivity 3.7 and HowLongToBeat 3.13 were tested. Online HLTB updates need a local HLTB sign-in, the correct existing mapped profile entry and uploads enabled. Missing online entries are not created automatically. Other extensions’ sign-ins are not copied.

While you play

Sync runs in the background. Ordinary launches use local saves immediately; cloud save replacement waits while a game starts or runs. Known conflicts need review. Provider outages and large transfers can take longer; there is no universal ten-second cloud guarantee.

No Playnite Link subscription or hosted backend is required. Your provider’s storage limits and pricing apply.
